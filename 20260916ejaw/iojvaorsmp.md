# 昨晚，深圳200多个医生都去了这里，为什么......

> 更新时间：2026-09-16 (UTC+8)

昨天3月15日，是一个寻常的周末。

有一群人，没有陪伴在孩子们身边，也没有与家人共进晚餐，她们从深圳各大医院下班后，匆匆往一个地方汇聚。

这些医生们究竟去哪儿呢?

原来，她们都到了深圳华强广场酒店紫荆厅，参加深圳中山泌尿外科医院举办的生殖医学交流会议。

李瑾 主任

晚上19点，来自深圳市宝安区妇幼保健院的李瑾主任，主持了本场交流会。她上台对200余位专家济济一堂共襄盛会很感慨，敬佩各位同道牺牲休息时间来学习、交流。

会议现场

深圳中山泌尿外科医院生殖中心莫美兰主任致欢迎致辞。她希望本次学术交流会议能让众人有所收获，在互相交流中，学以致用，一起为不孕不育患者谋福音。

莫美兰 主任

生殖助孕团队徐芬医生首先上台作课题分享。她在《早发性卵巢功能不全(POI)》中讲到，早发性卵巢功能不全对于31-37岁女性影响大。这部分女性有生育要求，但随着年龄增长，她们的生育力下降明显。发生POI后，患者会出现月经改变、低刺激素等症状。在临床上，这部分病人是关注目标人群，也是不孕不育治疗困难人群。在IVF(试管婴儿技术)助孕及辅助治疗中，需要对POI患者进行多角度、多学科综合治疗。

徐芬 医生

张宏展博士做了题为《辅助生殖技术现状解读》的分享。对目前国内外的辅助生殖技术发展，张博士做了思考和总结。在课题中，她详细讲解了IVF助孕技术促排卵方案的转变，并分享了新鲜周期和冷冻周期的黄体支持方案;也结合自身胚胎实验室工作经历，数据分析了OHSS(卵巢过度刺激综合征)下降的原因、避免多胎妊娠发生的原因及介绍了囊胚技术的发展;在ART(人工辅助生殖)质量管理中，她强调了病人安全性这一重要的治疗原则。

张宏展 博士

生殖泌尿男科主任宋明哲做了题为关于《男性不育的规范化诊断与治疗》的分享。他在讲课中主要介绍了不育治疗的四大原则，分享了男性不育诊治路径，对各种疾病所引起的男性不育症做了深入浅出的介绍。并重点阐述了严重少精子症和无精子症的规范诊治问题，强调了病因检查的重要性，指出对严重少精子症切不可盲目用药，以免进一步损害生精功能。

宋明哲 主任

三位医生的临床经验和医学思考传达给了现场同道，反馈热烈。现场提问环节中，许多的专家踊跃发言，提出了各自的疑惑。莫美兰主任、张宏展博士、宋明哲主任和徐芬医生一一解答。

两个半小时的医学沙龙会议结束后，还有许多的人围着医生们积极探讨，抓住这来之不易的“取经”机会。
